# 0.2.0-alpha.2

发布日期：2026-11-16。本版本仍为实验性预发布，目标环境固定为 Linux x64、Node.js 22.23.5、QQ 3.2.35-54395。其他 QQ 构建、系统架构和所有权限/参数变体不在已验证范围内。

## 修复与补充

- 原生 MSF 通道采用有界可取消队列、统一总期限及会话隔离；由项目 C 源码正式构建并核对 manifest、源码和二进制摘要，删除旧探针与 loader。
- 修复 QQ 已返回精确成功送达回调、但 `sendMsg` Promise 持续等待而误报超时的问题。当前会话、目标、发送者及真实消息 ID 必须匹配；明确拒绝仍失败，结果不明不自动重发。
- 消息映射引入带校验的增量 WAL，保留旧 v1 消息 ID。关闭、备份及异常持久化处理避免旧内存覆盖已落盘状态。
- 补充语音导出、公告、荣誉、精华、表态、分组、头像、状态、OCR及目录类固定入口，按账号当前能力门控；不开放任意 kernel、JavaScript 或 SSO。
- 语音、视频、文件支持规范 base64 输入，整条消息的内联媒体合计上限 10 MiB，整批校验后进入账号私有暂存。
- 修复公告正文实体处理、备份预览竞态、账号配置事务和设置迟到响应覆盖；日志扫描有界并支持分页与不完整结果提示。
- 普通事件和媒体转换使用独立有界工作槽；专用 Docker 服务及消息恢复文档纳入交付。

## 当前边界

- **已有 `node.data.id` 的合并发送变体关闭。** 实际调用曾送达且内容完整，但目标 QQ 回调缺乏可证明请求与目标消息关联的标识；正式 OneBot 和内部 RPC 在派发前返回不支持。自定义本账号文字/图片合并及读取继续可用，结果不明的旧动作不重发。
- `share` 新闻卡片在目标客户端展示失败，出站保持停用。合并内语音、视频及引用上下文、通用 JSON/XML 出站、更多群通知仍未完成真实验证。
- 仍未实现匿名禁言、匿名开关、cookies/CSRF/credentials、`set_restart`、`clean_cache` 七项标准动作；不返回占位成功。
- 新增头像、在线状态、分组、删除好友、群主头衔、OCR等参数变体有源码与离线覆盖，不能一概标为本轮真实业务通过。AI音色目录不等于AI语音生成/发送。
- 私聊文件经典 Offline 备用通道未通过；语音接收取决于账号内真实文件或已验证下载器；`get_record` 返回容器内路径，跨容器格式导出仍有限制。
- 备份、WAL、持久化异常主要通过离线故障注入；没有执行真实云端断电、破坏性恢复或整机重启。专用 daemon 恢复与整机 reboot 分别记录。
- QQApi 自身的原生 sender/独立云测不属于本发布的成功结论，不能继承 Freshwater 结果。

更多具体参数与限制见 [能力边界](../capability-limits.md)及 [原生验收](../native-validation-20261116.md)。

## 下载、安装与校验

[本版本附件](https://github.com/l52312516-cell/Freshwater-dolphin/releases/tag/v0.2.0-alpha.2)包括源码包、Linux x64 镜像、能力目录及 SHA256SUMS。QQ 程序、登录数据、真实配置、凭据及消息映射不随源码或镜像发布。

将下载文件放到工作区 `outputs/`，在 Bash 中从该目录核对：

```sh
sha256sum --ignore-missing -c SHA256SUMS
gzip -dc freshwater-dolphin-0.2.0-alpha.2-linux-x64.tar.gz | docker load
```

首次部署按 [README](../../README.md)准备受支持 QQ 安装包与私有目录。已有部署继续挂载原 `work/`；升级前备份且等待账号停写，不删除映射或 WAL。需要回滚到不识别 WAL 的旧版本时，先按 [存储与恢复](../storage-and-recovery.md)执行 checkpoint。
