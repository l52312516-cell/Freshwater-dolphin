# 0.2.0-alpha.3

本版为 **Alpha / 小范围试运行发行版**，包含 Linux QQ 适配改进和 Windows x64 离线预览包。稳定参考：Linux x64、QQ `3.2.35-54395`、Node.js 22。

## 主要变化

- 消息入站逐段兼容：合法未知片段原位使用文字占位，并在事件、查询、历史与合并转发读取中返回 `_freshwater` 完整性信息。身份冲突、非法结构、超限与严格出站继续拒绝。
- 接收日志区分完整、部分与整条跳过；API 诊断保留有界原因、阶段、关联 ID 与构建信息，不将资源不可用一概称为接口不支持。
- QQ 完整构建、安装包和实际 wrapper 指纹按账号管理。其他 Linux 3.2.x 构建可由管理员显式开启受限实验模式；native 后端保持精确绑定。
- 版本切换使用停写、完整状态快照、身份核验和失败恢复事务。备份升级到 v3，并兼容 v2。
- Windows 新增 `Freshwater.cmd → Node.js → Alpine WSL2 → Docker Engine → Linux QQ`。附带离线运行资产、回环实例认证、端口检查、心跳租约、95 秒容器停止宽限及冷升级快照。
- 保留双账号隔离和 `legacy → 17700`、`secondary → 17701` 两条 AstrBot 路由。
- 整理首页与专题导航，新增中文 Issue / PR 模板、贡献与安全说明，并补充持续集成和审核约定。

## 下载与使用

- **Windows x64 ZIP**：解压后先核对 SHA256，在管理员终端运行 `Freshwater.cmd install`，检查差异后执行；详见 [Windows 运行说明](../windows-runtime.md)。
- **源码包**：包含 Freshwater 源码和文档；不含登录态、私有配置、运行缓存或 QQ 安装包。Linux 用户按 [部署说明](../linux-deployment.md) 准备官方 QQ 包并构建。
- **校验与依赖清单**：使用对应资产的 `.sha256` 和随附清单。Windows 离线二进制包内置 Linux QQ 安装内容，第三方条款见 [声明](../../THIRD_PARTY_NOTICES.md)。

## 验证范围

本轮实施基线验证：Windows 完整自动化 2073 项中 **2057 通过、0 失败、16 跳过**；Linux 镜像完整 QA **2071 通过、0 失败、2 平台跳过**。WebUI 29 项及 TypeScript / Vite 构建通过。最终启动器增量与中文空格路径验证：Windows 31 通过、1 权限跳过；Linux 37 通过、2 平台跳过，均 0 失败。平台跳过不作为业务通过计数。

Linux `/bin/sh` 的 EOF、心跳、停止失败、Docker 不可达，以及冷快照与中断恢复测试使用受控替身；镜像 QA 使用 `network=none` 和 Node 入口，不启动真实 QQ。发布文档与社区自动化的新增检查另由本版 CI 记录。

**尚未完成 Windows 真实 WSL 安装、QQ 双账号登录、AstrBot 联调及安装/运行/更新磁盘峰值测量。** 本轮未替换线上容器，也未恢复旧批量 QQAPI 写入测试。Windows QQ 9.9.x 原生与其他 QQ 完整 build 的真实业务证据不在本版通过范围。

已有 Linux 基线的真实验证记录保留于各 [接口专题](../README.md)，不会继承为新构建证据。接口名称、方法存在、账号在线、空页和自动化测试通过，均不等于全部参数或业务已真机认证。当前能力以每账号 `get_capabilities` 为准。
