# 0.2.0-alpha.3

验证日期：2026-11-16。实验版本；Linux x64、QQ `3.2.35-54395`、Node.js 22。

新增六项只读 QQAPI，具体参数与分页见 [QQAPI 扩展](../qqapi-extensions.md)。补充当前账号能力浏览器和设置离开提示，快速操作默认关闭，TLS 配置不完整时拒绝启动。查询保留真实未决预算、会话与身份校验、有界 JSON 响应及加密分页游标。

Windows 全量 1240 项：1237 通过、3 平台相关跳过；Linux 容器全量 1240 项全部通过。前端 29 项、TypeScript 与 Vite 构建通过。原生 manifest、镜像内 98 个源码文件一致性核对通过。

双账号真实群详情、群扩展、禁言列表、本人资料点赞、既有消息回应者查询成功。禁言列表使用完整成员快照与真实禁言时间，避免目标 QQ 中专用调用不结束的问题；只返回已验证的明确成员字段。本人资料点赞时间支持实际安全整数及精确字符串。

**收藏查询在两个账号均被 QQ 以 `errCode=5` 拒绝，尚未通过实机成功验收。** 即使响应携带空数组仍失败；错误保留安全业务码，未自动回退。空禁言/回应样本不代表非空和多页变体已通过。源码能力的 `available` 仅说明当前方法可用，不能代替业务结果。

云端管理鉴权、CSRF、双账号能力路由和浏览器桌面/手机布局通过；升级保留既有消息映射，两个账号及 AstrBot 连接正常。验证保持只读，没有制造新的 QQ 写入样本。当前交付为本地源码包和云端已部署镜像，未发布新的 GitHub Release。
