# 账号收藏表情

收藏表情使用当前已认证账号的真实目录。固定协议与业务处理分别位于 `custom-face-protocol.cjs`、`custom-face.cjs`，OneBot 适配为 `custom-face-actions.cjs`。调用方不能选择任意 SSO 命令、protobuf 字段、上传节点、凭证或宿主机文件路径。

| action | 参数 | 返回与确认依据 |
| --- | --- | --- |
| `fetch_custom_face` | `count` 默认 10，0–1000；`return_type` 为 `url`（默认）或 `id` | 获取本账号完整目录后，返回请求数量的真实 URL 或资源 ID。 |
| `fetch_custom_face_detail` | `count` 默认 48，0–1000 | 返回 `{emoji_id,resId,url,md5,desc}` 数组；详情应答只允许属于本次目录的 ID，MD5 必须匹配。协议未返回备注的条目表示没有保存的备注，`desc` 为空字符串。 |
| `add_custom_face` | `file` 仅支持本账号 `fwd-image-…` 句柄或规范 `base64://` 图片 | 返回 `{emoji_id}`。先按实际图片计算摘要，固定 BDH 申请与 Highway 上传要求完整字节 ACK，再从真实目录确认该 ID；已在目录的同内容图片直接返回已观察 ID。 |
| `delete_custom_face` | 完整 `emoji_id` | 目录确认属于本账号后只派发一次删除，读回目录确认不存在才返回 `null`。 |
| `modify_custom_face` | 完整 `emoji_id`，`desc` 默认空串、最多 1024 UTF-8 字节 | 派发固定备注请求后，从真实详情读回相同备注才返回 `null`。 |
| `move_custom_face_to_front` | 完整 `emoji_id` | 读取完整顺序，执行固定移动命令和完整顺序同步两步，读回相同完整顺序才返回 `null`。不支持任意位置。 |
| `send_custom_face` | `emoji_id` 为完整资源 ID 或 32 位 MD5；`group_id`/`user_id` 二选一；可选 `reply_to` | 从本账号目录唯一解析资源，固定官方图片地址下载并校验 MD5，准备真实 `picSubType:1`、`[动画表情]` 元素；复用现有原生发送、回复定位和消息存储，只在目标、摘要和表情子类型均匹配的实际消息确认后返回 `{message_id}`。 |

目录和删除采用固定 `Faceroam.OpReq`；详情、备注与顺序同步采用固定 `0x902e_1`，移动采用 `0x902f_1`。详情协议中没有备注的条目可能省略，不能由此断言该表情不存在；存在性始终以完整目录为准。响应缺目录容器、重复 ID、跨账号 ID 或总数与条数不同均失败。

新增收藏采用固定 `HttpConn.0x6ff_501` 获取上传节点，再固定 `ImgStore.BDHExpressionRoam` 获取上传 ticket，使用 commandId 9 的 Highway 帧发送实际图片字节。仅允许认证响应内提供的公网 IPv4 和有效端口，不接受调用方提供上传目标。HTTP 成功本身不足以确认添加；必须通过精确上传大小 ACK 和后续真实目录读回。ticket 不进入公开 RPC 结果。图片最多 10 MiB；规范 base64 在 OneBot 侧导入本账号受控图片句柄，IPC 不传大段 base64。

发送收藏表情保留真实收藏表情子类型；普通图片发送路径保持其既有行为。准备过程只读取固定 `https://p.qpic.cn/qq_expression/<当前UIN>/<真实ID>/0`，禁止重定向，按图片上限读取并校验实际格式及 MD5。下载内容导入本账号临时图片资源、复制至 QQ 原生缓存后移除临时资源。未知目录 ID、摘要不符、普通图片子类型或无真实消息确认都明确失败。

一个账号进程最多 4 个实际未完成收藏表情操作，同一时间最多一个目录修改操作。外层超时不会释放仍未完成的底层请求或修改锁；所有步骤共用调用方截止时间，最长 60 秒。会话、账号和 UID 改变后拒绝结果，不自动重发写请求。多步移动若中途失败可能已经部分生效，调用方应重新读取目录确定当前状态。

离线测试覆盖七动作适配、固定 wire、真实目录/备注/顺序读回、Highway 帧与 ACK、上传图片摘要、base64/受控句柄边界、收藏表情子类型、真实消息 ID 及跨会话/超时锁。当前写入、删除、备注和排序没有执行真实账号云端验收；这些离线实现不能当作该范围已经实测。在线验收记录应另行注明实际目标版本和测试对象。
